## 二、天德日

### 2.1 定义

天德是择日学中的吉神。天德日是指**日柱的天干**与**当月天德所对应的天干**相合之日。

### 2.2 推算规则

每个月份对应一个天德天干，该天干之日即为天德日：

| 月份 | 月支 | 天德天干 | 天德日举例 |
|------|------|---------|-----------|
| 正月 | 寅 | **丁** | 丁卯日、丁丑日、丁亥日、丁酉日、丁未日、丁巳日 |
| 二月 | 卯 | **申**（地支） | 壬申日、甲申日、丙申日、戊申日、庚申日 |
| 三月 | 辰 | **壬** | 壬辰日、壬寅日、壬子日、壬戌日、壬申日、壬午日 |
| 四月 | 巳 | **辛** | 辛巳日、辛卯日、辛丑日、辛亥日、辛酉日、辛未日 |
| 五月 | 午 | **亥**（地支） | 乙亥日、丁亥日、己亥日、辛亥日、癸亥日 |
| 六月 | 未 | **甲** | 甲子日、甲寅日、甲辰日、甲午日、甲申日、甲戌日 |
| 七月 | 申 | **癸** | 癸未日、癸巳日、癸卯日、癸丑日、癸亥日、癸酉日 |
| 八月 | 酉 | **寅**（地支） | 丙寅日、戊寅日、庚寅日、壬寅日、甲寅日 |
| 九月 | 戌 | **丙** | 丙寅日、丙子日、丙戌日、丙申日、丙午日、丙辰日 |
| 十月 | 亥 | **乙** | 乙亥日、乙酉日、乙未日、乙巳日、乙卯日、乙丑日 |
| 十一月 | 子 | **巳**（地支） | 己巳日、辛巳日、癸巳日、乙巳日、丁巳日 |
| 十二月 | 丑 | **庚** | 庚寅日、庚子日、庚戌日、庚申日、庚午日、庚辰日 |

### 2.3 速查公式

**天德对应的六十甲子序号表：**

以六十甲子的序号（1-60）来定位天德日：

| 月份 | 天德六十甲子 | 序号 |
|------|------------|------|
| 正月（寅） | 丙寅 | 3 |
| 二月（卯） | 辛卯 | 28 |
| 三月（辰） | 壬辰 | 29 |
| 四月（巳） | 丁巳 | 54 |
| 五月（午） | 庚午 | 7 |
| 六月（未） | 癸未 | 20 |
| 七月（申） | 丙申 | 33 |
| 八月（酉） | 辛酉 | 58 |
| 九月（戌） | 壬子 | 49 |
| 十月（亥） | 丁丑 | 14 |
| 十一月（子） | 庚寅 | 27 |
| 十二月（丑） | 癸卯 | 40 |

**规律：** 天德日六十甲子序号之间相差依次为 25、3、25、13、13、13、25、31、13、13、13（循环特征）。

### 2.4 推算步骤

1. 确定当前日期处于哪个节气月份（查 1.4 节气表）
2. 根据月份查出天德天干（查 2.2 表）
3. 查看当天的日柱天干是否与天德天干一致
4. 若一致，则当天为天德日

**示例：** 2026年7月12日
- 7月12日在小暑（约7月7日）之后、立秋（约8月7日）之前 → 属于**六月（未月）**
- 六月天德天干为 **甲**
- 查万年历：2026年7月12日日柱为**甲子日**
- 天干为甲 → **是天德日** ✓

## 三、天德合日

### 3.1 定义

天德合是与天德天干相合之日（按天干五合）。

### 3.2 推算规则

## 四、月德日

### 4.1 定义

月德是择日学中的另一吉神。月德日是指**日柱的天干**与**当月月德所对应的天干**相合之日。

### 4.2 推算规则

| 月份 | 月支 | 月德天干 | 月德日举例 |
|------|------|---------|-----------|
| 正月 | 寅 | **丙** | 丙寅日、丙子日、丙戌日、丙申日、丙午日、丙辰日 |
| 二月 | 卯 | **甲** | 甲子日、甲寅日、甲辰日、甲午日、甲申日、甲戌日 |
| 三月 | 辰 | **壬** | 壬辰日、壬寅日、壬子日、壬戌日、壬申日、壬午日 |
| 四月 | 巳 | **庚** | 庚寅日、庚子日、庚戌日、庚申日、庚午日、庚辰日 |
| 五月 | 午 | **丙** | 丙寅日、丙子日、丙戌日、丙申日、丙午日、丙辰日 |
| 六月 | 未 | **甲** | 甲子日、甲寅日、甲辰日、甲午日、甲申日、甲戌日 |
| 七月 | 申 | **壬** | 壬辰日、壬寅日、壬子日、壬戌日、壬申日、壬午日 |
| 八月 | 酉 | **庚** | 庚寅日、庚子日、庚戌日、庚申日、庚午日、庚辰日 |
| 九月 | 戌 | **丙** | 丙寅日、丙子日、丙戌日、丙申日、丙午日、丙辰日 |
| 十月 | 亥 | **甲** | 甲子日、甲寅日、甲辰日、甲午日、甲申日、甲戌日 |
| 十一月 | 子 | **壬** | 壬辰日、壬寅日、壬子日、壬戌日、壬申日、壬午日 |
| 十二月 | 丑 | **庚** | 庚寅日、庚子日、庚戌日、庚申日、庚午日、庚辰日 |

### 4.3 速记规律

月德天干按 **丙→甲→壬→庚** 循环，每四个月重复一次：

- 第 1、5、9 月（寅、午、戌）→ **丙**（火局阳干）
- 第 2、6、10 月（卯、未、亥）→ **甲**（木局阳干）
- 第 3、7、11 月（辰、申、子）→ **壬**（水局阳干）
- 第 4、8、12 月（巳、酉、丑）→ **庚**（金局阳干）

**三合局阳干规律：**
- 寅午戌三合火局 → 阳干 **丙**
- 亥卯未三合木局 → 阳干 **甲**
- 申子辰三合水局 → 阳干 **壬**
- 巳酉丑三合金局 → 阳干 **庚**

### 4.4 推算步骤

1. 确定当前日期处于哪个节气月份
2. 根据月份查出月德天干
3. 查看当天的日柱天干是否与月德天干一致
4. 若一致，则当天为月德日

| 七月 | 申 | 壬 | **丁** | 丁壬合化木 |
| 八月 | 酉 | 庚 | **乙** | 乙庚合化金 |
| 九月 | 戌 | 丙 | **辛** | 丙辛合化水 |
| 十月 | 亥 | 甲 | **己** | 甲己合化土 |
| 十一月 | 子 | 壬 | **丁** | 丁壬合化木 |
| 十二月 | 丑 | 庚 | **乙** | 乙庚合化金 |

### 5.3 有趣的对称关系

天德与月德之间存在对称关系：
- **月德合 天干 = 天德 天干**（数值相同，但神煞不同）
- **天德合 天干 = 月德 天干**（数值相同，但神煞不同）

这是两种不同的吉神，不可混淆。

## 六、天赦日

### 6.1 定义

天赦日是择日学中最为特殊的吉日之一，主赦免过失、消灾解厄。天赦日的推算与季节（非月份）相关。

### 6.2 推算规则

**核心口诀：**

> **春戊寅，夏甲午，秋戊申，冬甲子**

具体对应：

| 季节 | 包含月份 | 天赦日柱 | 六十甲子序号 |
|------|---------|---------|------------|
| 春 | 正月（寅）、二月（卯）、三月（辰） | **戊寅** | 15 |
| 夏 | 四月（巳）、五月（午）、六月（未） | **甲午** | 31 |
| 秋 | 七月（申）、八月（酉）、九月（戌） | **戊申** | 45 |
| 冬 | 十月（亥）、十一月（子）、十二月（丑） | **甲子** | 1 |

### 6.3 天赦日的特征规律

- **春、秋** 天赦日天干为 **戊**（戊为中央土，有赦免之意）
- **夏、冬** 天赦日天干为 **甲**（甲为天干之首，有新生之意）
- **春、夏** 天赦日地支为 **寅、午**（阳支）
- **秋、冬** 天赦日地支为 **申、子**（阳支）

天赦日六十甲子序号：1、15、31、45，间隔分别为 14、16、14。

### 6.4 推算步骤

1. 确定当前日期处于哪个节气月份
2. 根据月份确定所属季节：
   - 寅、卯、辰月 → 春季 → 天赦日为 **戊寅日**
   - 巳、午、未月 → 夏季 → 天赦日为 **甲午日**
   - 申、酉、戌月 → 秋季 → 天赦日为 **戊申日**
   - 亥、子、丑月 → 冬季 → 天赦日为 **甲子日**
3. 查万年历，看当天日柱是否为对应的天赦日柱
4. 若一致，则当天为天赦日

### 6.5 示例

**2026年7月12日：**
- 7月12日在小暑之后、立秋之前 → 未月 → **夏季**
- 夏季天赦日为 **甲午日**
- 查万年历：2026年7月12日日柱为甲子日，非甲午日
- → **不是天赦日** ✗

**2026年7月28日：**
- 仍在未月 → **夏季**
- 查万年历：2026年7月28日日柱为**甲午日**
- → **是天赦日** ✓

- 目标日期（公历）

### 输出
- 是否为天德日、月德日、天赦日

### 步骤

```
1. 获取目标日期的公历日期
2. 查询万年历，获取该日期的：
   - 日柱干支（天干 + 地支）
```

## 八、注意事项

1. **月份以节气为界**，不以农历初一为界，这是推算的关键前提
2. **日柱干支**需通过万年历查询，不能简单推算
3. 天德合、月德合虽与天德、月德有数值对称关系，但**是不同的神煞**，各有独立的择日意义
4. 天赦日按**季节**而非月份判断，每季只有一个天赦日
5. 实际择日还需综合考虑其他神煞、冲煞等因素，天德、月德、天赦仅为其中一部分参考
