# Phase 3.2.3：本命合参扩展（年命纳音）

> 日期：2026-09-09　状态：已完成
> 前置：Phase 3.2（日柱）、3.2.1（年命 地支）、3.2.2（日课年柱 地支）。本次纳入**年命纳音五行生克**。

## 一、目标
在既有五维度（日/年/课年 地支）基础上，新增**年命纳音**维度：
- 候选日 **日柱纳音** vs 本命年命纳音 → ctx=`日纳`
- 候选日 **年柱(日课年柱)纳音** vs 本命年命纳音 → ctx=`年纳`
同一套「仅展示 + 同等级软排序、不改吉凶定级」铁律；纳音生克仅影响排序权重。

## 二、数据依据（非捏造）
- **六十甲子纳音表**：标准经典纳音表（甲子乙丑海中金 … 壬戌癸亥大海水），固定经典参照，非凭记忆捏造。
  校验：`Object.keys(NAYIN).length===60`，抽样 `丙午→水/庚午→土/甲子→金` 正确。
- **五行生克**：`木生火、火生土、土生金、金生水、水生木`；`木克土、火克金、土克水、金克木、水克火`。
- 用户年命纳音 = 保存命盘 `pillars.year` 完整干支查 NAYIN（如 丙午→水）。
  候选日纳音 = `d.gz.year`(日课年柱) / `d.gz.day`(日柱) 查 NAYIN（来自 computeDayFromLunar 真实干支）。

## 三、纳音生克判定（纯函数 `_nayinRelation`）
比较 **日课某柱纳音(d)** vs **本命年命纳音(y)**，仅标三种决策相关态：
- `d 克 y`（日课克本命）→ **纳音克（凶）**，权重 −10
- `d 生 y`（日课生本命）→ **纳音生（吉）**，权重 +3
- `d == y`（同五行）→ **纳音比和（平吉）**，权重 +2
- `y 克 d`（本命克日课，我克为财）/ `y 生 d`（本命生日课，我生为泄）→ 中性，**不标注**

> 设计取舍：仅标「日课对本命」的生/克/比和；「本命对日课」的生克属中性（财/泄），不标，避免噪声与命理硬排除（保持与地支维度一致的「软排序不改 grade」铁律）。

- 纳音严格按标准六十甲子表（非捏造）；生克仅「日课对本命」的生/克/比和 标，中性（本命克/生 日课）不标。
