## 地盘/人盘遮挡修正
- 问题：切换地盘（decadal/大限）或人盘（yearly/流年）时，运曜并入顶部星耀行，星列数暴涨到 36–40，导致星耀区（左上，约 47px 高）与居中「流年/小限/大限」块大面积重叠（ovMid≈1090px²）。
- 根因：`.zw-palace-mid` 使用 `top: 52%; transform: translate(-50%, -50%)`，中部块上缘被向上提了约自身高度的一半，扎进星耀区。
- 方案：把中部块改为“置顶在星耀区下方”，并在剩余空间中垂直居中，同时收窄宽度避免溢出宫格。
- 改动（`web/css/ziwei.css`）：
  - `.zw-palace-mid`：`top: 52px; bottom: 22px; transform: translateX(-50%); width: calc(100% - 10px);` + `display:flex; flex-direction:column; justify-content:center; align-items:center;`。
  - 星耀区保持原四行竖排不动；底部 22px 继续留给十二神/长生干支/宫名。
- 验证：Playwright 在 decadal/yearly 两视图下用 `getBoundingClientRect` 测量 `.zw-palace-stars` 与 `.zw-palace-mid/.zw-palace-leftbot/.zw-palace-rightbot/.zw-palace-name` 的交集，返回 0（无遮挡）；无 JS 报错。
- 截图产物：`ziwei_scope_decadal.png`、`ziwei_scope_yearly.png`。

## 新增「保存排盘」功能
- 需求：紫微斗数排盘增加保存信息功能，方便下次查询。
- 方案：前端 `localStorage` 持久化保存排盘输入（不改动后端无状态 HMAC API），下次载入时重新计算，避免陈旧数据。
- 数据：`{ id, label, form:{name,sex,calType,y,m,d,hour,min,zty,jd,wd,province,region,location}, createdAt }`，键 `zw_saved_charts`。
- 改动：
  - `web/js/ziwei-ui.js`：
    - 提取 `_applyFormToInputs(form)`（原 `_restoreForm` 的应用段复用）。
    - 新增 `_getSaved`/`_setSaved`/`_delSaved`/`_snapshotForm`/`_saveCurrentChart`/`_loadSaved`/`_renderSavedList`/`_esc`/`_bindSaved`。
    - `_formBlockHTML` 中「排盘」旁新增「保存此排盘」按钮（`.zw-btn-ghost`）。
    - `buildShellHTML` 左栏新增 `_savedBlockHTML` 卡片（搜索框 + 列表 + 载入/删除）。
    - `show()` 调用 `_bindSaved()` 初始化列表。
  - `web/css/ziwei.css`：新增 `.zw-btn-row`、`.zw-btn-ghost`、`.zw-btn-mini`、`.zw-btn-danger`、`.zw-saved*` 系列样式，匹配浅色宣纸主题。
- 验证：Playwright 全流程（保存 → 列表显示 → 刷新仍在 → 搜索匹配/不匹配 → 载入回填并重排 → 删除清空），断言全部通过，无 JS 报错。
