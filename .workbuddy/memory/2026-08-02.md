# 2026-08-02 工作日志

## 故障：手机扫码「全部加载、请求失败」— 根因与修复

### 根因（已坐实）
- 手机经局域网 HTTP（`http://192.168.1.7:3000`，非 localhost）访问 → 属 **non-secure context**。
- 浏览器在非安全上下文下 `crypto.subtle === undefined`；前端 HMAC 签名强依赖 `crypto.subtle` → 每条 API 请求 `_sign()` 抛 `TypeError` → 全部请求失败。
- 电脑用 `localhost` 被豁免为安全上下文，故电脑正常、手机全废。此即「电脑能用、手机全挂」的本质。

### 修复内容
1. **新增 `web/js/sha256.js`**：零依赖纯 JS 实现 SHA-256 / HMAC-SHA256（UTF-8 编码兼容老 WebView 的 `TextEncoder` 缺失回退）。导出 `sha256Bytes / hmacSha256Hex / utf8Bytes / bytesToHex`。
2. **`web/js/api.js`**：import `hmacSha256Hex`；新增 `_subtleOK` 探测 + 重写 `_sign()`（WebCrypto 优先，失败/不可用回退 PureJS）；导出 `signBackend()`（'WebCrypto'|'PureJS'）。
3. **`web/js/hmac-spec.js`**：`genNonce()` 增加 `crypto.getRandomValues` 缺失回退（时间戳+Math.random，仅防重放）。
4. **`web/js/settings-ui.js`**：消除硬编码密钥副本，改为 import `HMAC_KEY` 与 `hmacSha256Hex`，签名加回退（第二处同病，全局 grep 发现）。
5. **`web/sw.js`**：`APP_SHELL` 预缓存增加 `/js/sha256.js`。
6. **`web/app.html` & `web/index.html`**：SW 注册加 `window.isSecureContext` 判断，避免 HTTP 下误报。
7. **新增 `web/diag.html` + `web/diag-qrcode.png`**：手机端自检页（协议/安全上下文/subtle/SW/TextEncoder 状态 + 固定向量签名自检 `ac70ee24` + 4 接口实连测试 + verdict），金箔暗色玻璃风。

### 单一真源纪律
密钥 `HMAC_KEY`、消息格式 `buildMessage` 三端（服务端 `lib/hmac.js` / 前端 `hmac-spec.js` / 回退 `sha256.js`）保持一致。
